# Kronos AI CRM - User Guide & Feature Manual

## Overview
Kronos AI CRM is an autonomous career intelligence system designed to automate multi-portal job scanning, ATS resume optimization, automated cold outreach, and recruitment conversion tracking.

---

## Key Modules

### 1. ⚡ 8 Dynamic Visual Themes
Choose between 8 high-contrast visual themes:
- **Cyber Cyan** (High-tech navy & electric cyan)
- **Neon Violet** (Midnight purple & outrun magenta)
- **Emerald Grid** (Matrix green)
- **Solar Gold** (Sunburst gold)
- **Crimson Void** (Cyber red)
- **Cyber Synthwave** (Sunset pink)
- **Midnight Matrix** (Bio-luminescent green)
- **Hyper Crimson** (Fiery magma red)

3D Canvas particles and robot eye glows automatically update when switching themes.

---

### 2. 🔍 Multi-Portal Job Search
Scan and filter live opportunities across LinkedIn, Indeed, Glassdoor, Naukri, Monster, and Google Jobs. Direct portal links are accessible with or without login credentials.

---

### 3. 📄 Resumes & ATS Analyzer
- Create and manage role-specific resumes (e.g., Software Engineer, Java Developer, AWS Engineer, DevOps, Mechanical Engineer).
- Run ATS scoring checks and truthful AI optimizations with full dark-glass code editor controls.

---

### 4. 🌐 Connected Job Portals
- Enter credentials in Profile Setup to mark portals as `✓ Connected & Ready`.
- Add custom job portals (e.g., Wellfound, ZipRecruiter) which automatically register in the Portals view.

---

### 5. 🤖 AI Chatbot Assistant
Interact with the embedded AI assistant for STAR-method interview preparation, salary negotiation, and resume feedback via text or voice.
